SOLO DM — D&D 3.5e-inspired offline PWA

INSTALL ON SAMSUNG ANDROID
1. Extract this ZIP on your phone or computer.
2. Host the folder on an HTTPS static host (for example GitHub Pages). PWA installation and service workers require HTTPS or localhost.
3. Open the hosted index.html in Chrome on your Samsung.
4. Chrome menu (⋮) → Add to Home screen or Install app.
5. Launch Solo DM from the home screen. After the first successful load, the app shell is cached for offline use.

For local testing on a computer, run: python -m http.server 8000
Then visit http://localhost:8000.

INCLUDED
- Free-form action input with procedural action interpretation
- Player-entered physical d20 checks and modifiers
- Character sheet, abilities, skills, combat stats and saves
- Dice roller and custom dice expressions
- Inventory, coin tracking and treasure log
- Procedural travel, NPC interactions, encounters, rest and time
- Journal, local campaign save, JSON export/import
- Offline PWA shell

LIMITATIONS
This is a playable starter engine, not a full natural-language AI Dungeon Master. It recognizes common action patterns and uses procedural narrative responses. Some D&D 3.5e rules are simplified; use your rulebooks for authoritative adjudication. Campaign data is stored in the device/browser and should be exported periodically.
